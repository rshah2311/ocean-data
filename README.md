# ocean-data

Global ocean data (sea temperature, salinity and more), the scripts that pull it, and code to visualize it.

## Layout

| Folder     | What goes there                                    |
|------------|----------------------------------------------------|
| `scripts/` | Scripts that download and update the data          |
| `data/`    | The data, refreshed after each pull                |
| `viz/`     | Code for charts and maps of the data               |

## Status

Project skeleton only. Data sources and pull schedule are still to be decided.
